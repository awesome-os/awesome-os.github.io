The History of Computers & The Internet

The honest lineup of the real builders who invented programming, bits, compilers, Moon-landing safe gates, the mouse, Unix, the Internet, the free Web, and open-source software — starting with the first programmer, Ada Lovelace.

George Boole & Claude Shannon

Alan Turing

The Universal Machine — The Universal Turing Machine — proof that ONE programmable machine can run ANY program

The Compiler — Teaching Machines Human Words — The first compiler (A-0) and machine-independent programming languages (COBOL)

Margaret Hamilton

Software Engineering & Safe Gates to the Moon — Software Engineering as a discipline + fault-tolerant priority recovery software for Apollo 11

 07 · 1968

Douglas Engelbart

The Mother of All Demos — The computer mouse, hypertext links, windows, video calls, and live shared documents

 08 · 1969–1972

Ken Thompson & Dennis Ritchie

Unix & C — The Quiet River Underneath — The Unix operating system and the C programming language

 09 · 1974–1985

TCP/IP & The Spanning Tree of the Internet — TCP/IP (how the Internet sends packets across Earth) + Spanning Tree Protocol (how networks avoid infinite loops)

Tim Berners-Lee

The World Wide Web — Given Away for Free — HTML, HTTP, URLs, the first web browser, and the first web server
