1. Constant-Time (@oblivious) Security Lattice & Real-Scale Benchmarks

StealifyLang enforces constant-time execution statically via ct-lattice.ts (CTValue<T>, CapabilityToken<TID>, ObliviousSabArena, and IR_OBLIVIOUS_BARRIER_FLAGS = 0x7):

  • Compile-Time Enforcement: Rejects data-dependent if/while/switch, early break/return/throw, dynamic heap/hash lookups, and variable-divisor / or % inside @oblivious blocks.
  • Measured Throughput (bench-real-scale.mts):
  • Specification Run (1,000,000 lookups, Stride = 16): 28.17M ops/sec (35.50 ns avg, 0 B loop heap allocation — 2.8× above the 10M ops/sec target).
  • L1-Resident Baseline (100% Read, N = 8): 46.39M ops/sec (21.6 ns avg, p99.9 = 27.8 ns, zero GC pauses).
  • Direct RAM-Composition & Bare-Metal Emission: ram-composition.mts and ts-on-stealify.mts lower @oblivious functions directly to verified branchless x86_64 machine code and UEFI PE32+ (BOOTX64.EFI) images.

2. T2 SDE Modernized: 1.96 KB Initramfs & 3.74 ms Cold Boot

Using Content-Addressable Storage (CAS) Merkle containers on x86_64 QEMU (repository/b8g-release-distributions-t2/):

  • Initramfs Size: 1.96 KB (t2-x86_64-initramfs.cpio.gz) vs. 650 MB upstream ISO (99.99% reduction).
  • Cold Boot Time: 3.74 ms to an interactive t2 shell prompt over Serial UART COM1 (0x3F8 / /dev/ttyS0).
  • Authentic CLI: Preserves genuine t2 info, t2 bench, t2 config, t2 find, and t2 build-target commands.

3. Universal Driver Interoperability Fabric & OS Research Methodology

  • Cross-OS Kernel Driver Fabric: nt-microabi-bridge.mts and universal-driver-fabric.mts bridge Windows PE32+ .sys (MDL), Linux ELF64 .ko (sk_buff), and macOS Mach-O .kext (IOBufferMemoryDescriptor) over unified zero-copy SAB DMA handles and lock-free Atomics IRQ rings.
  • 4-Stage Gated OS Research (research-os.md): Every major architectural claim in Awesome-OS must pass hypothesis → isolated microbenchmark → adversarial invariant verification → runnable test suite in-tree before shipping.
  • AI / Kinematics Experiments (AI_STUFF.md, LoL_AGENTS-SLERP.md, ECOMMERCE-API.md): Early LoRA/SFT training notes, SLERP agent-kinematics experiments (which later informed our nonholonomic unit-quaternion manifold in sections/manifold/), and AI-Buy storefront asset schemas are preserved in history without cluttering core OS runtime paths.
