Chapter 10: Zero-Q Agentic Compilers (ZER0Q + SUBSTRATE + SKIMMER)

"Never pay a stochastic neural network to recompute a state transition that a SHA-256 hash already proved."

1. Historical Contrast: Deterministic Compilers to Stochastic Agent Loops

The Green (1977), Red (1986), and Purple (2006) Dragon Books assumed a deterministic world: given source text S, a compiler executes a fixed pipeline (lex → parse → IR → optimize → emit) and produces a predictable binary B. Even when build systems scaled to remote clusters (Bazel, Goma, RBE), the execution model remained queue-based: enqueue a job, wait for a worker, compile from scratch on a cache miss, and store opaque artifacts.

In 2026, software engineering entered the agentic era: autonomous LLM reasoning loops (AGENTS.md, SKILL.md, MCP tool calls, shell execution, test verification) act as high-level semantic compilers that transform intent and codebases into verified patches. Yet early agent platforms repeated every Von Neumann mistake:

  • Wrapping LLM calls in ad-hoc scripts with no content addressing, re-burning hundreds of thousands of tokens on identical repository states.
  • Routing autonomous triggers through heavyweight broker queues that stall on retries and spawn duplicate runs on webhook storms.
  • Failing to pin the exact instructions, tool schemas, and filesystem snapshot — making agent runs unreproducible.

2. The White Dragon Architecture: ZER0Q + SUBSTRATE + SKIMMER

The White Dragon Book applies content-addressed compilation (Chapter 4) directly to autonomous agents by splitting the runtime into two strict planes (docs/plans/ZERO-Q-AGENT-RUNNER-PLATFORM-PLAN.md):

Triggers (Cron / Webhook / Git / CLI — DEADHAND)

│ Deterministic Control Plane (< 2 ms, Zero-Q)                │

│  SKIMMER      : H(AGENTS || SKILLS || Tools || Tree || Msg) │

                                   (Sandbox + Reasoning Loop + Verify)
                                               │
                                   Commit Output + Transcript + Proof
                                               └──────► SUBSTRATE-CAS
  • SUBSTRATE (CAS + KV): Stores immutable .b8p / SHA-256 content objects (instructions_hash, toolchain_hash, workspace_hash, output_tree_hash, transcript_hash, verification_hash) indexed by b8g-brain's SHA-256 CAS index, paired with a sub-millisecond KV plane for mutable aliases (alias:sec-audit:prod -> cas:sha256:...), optimistic SETNX leases, idempotency keys, and live token/USD budget counters.
  • SKIMMER (Pre-Flight Short-Circuit): Computes the canonical input_digest before booting any sandbox or spending a single LLM token. On a CAS hit, SKIMMER hydrates and returns the verified output in < 2 ms with 0 tokens burned.
  • ZER0Q (Execution Contract): Every autonomous run is a typed, replayable manifest rather than an untyped prompt string.
// Canonical Zero-Q pre-flight resolver (SKIMMER + SUBSTRATE)
export interface Zer0qInputDigest {
  readonly instructionsHash: string; // SHA-256(AGENTS.md + resolved SKILL.md)
  readonly toolchainHash: string;    // SHA-256(MCP schemas + sandbox image digest)
  readonly workspaceHash: string;    // UniversalVersionedSource Merkle root
  readonly promptCanonical: string;  // Deterministic canonical JSON prompt
  readonly modelId: string;
}

export async function skimmerResolve(
  input: Zer0qInputDigest,
  cas: SubstrateCas,
  kv: SubstrateKv
): Promise<{ hit: true; outputHash: string; latencyMs: number } | { hit: false; leaseId: string }> {
  const t0 = performance.now();
  const digest = sha256Canonical(input);
  const cached = await cas.getVerifiedOutput(digest);
  if (cached) {
    return { hit: true, outputHash: cached.outputTreeHash, latencyMs: performance.now() - t0 };
  }
  const leaseId = await kv.acquireAtomicLease(`lease:run:${digest}`, { ttlMs: 600_000 });
  return { hit: false, leaseId };
}
