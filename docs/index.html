Awesome-OS Documentation

Minimal, zero-bloat guide to get Electron / Sectium Browser Shell and the Awesome-OS Linux Desktop running from one shared v11 CAS (repository:// + project://).

B8G_ABI_MAGIC_V3 (0x33564742) v11 Hardlink CAS Zero Duplicate Electron MIT Rust Coreutils

1. Bootstrap holo-pm & awesome-os-desktop

Only two tools ever use a web bootstrap script: holo-pm and awesome-os-desktop. Everything else installs via holo-pm into your local ./bin/ as 0-byte hardlinks.

Windows (PowerShell)

# Open the Web OOBE OPFS Installer in browser:
# https://awesome-os.github.io/installer/

# Or download & launch Awesome-OS Desktop Greeter
irm https://raw.githubusercontent.com/awesome-os/installer/main/START-HERE.bat -OutFile START-HERE.bat; .\START-HERE.bat

Linux & macOS

# Launch Awesome-OS Desktop & v11 CAS Greeter
curl -fsSL https://raw.githubusercontent.com/awesome-os/installer/main/start-here.sh | sh

2. Get Electron & Sectium Browser Shell Running

sectium-browser (electron-sectium-browser-shell) and code-oss share one deduplicated Electron runtime in HOLO_CAS_DIR/v11 (587 MB combined RAM on Windows 11). 

# Install Electron + Sectium Browser Shell (hardlinks into ./bin/)
holo-pm install repository://github.com/awesome-os/sectium-browser@main
holo-pm install repository://github.com/awesome-os/code-oss@main

# Or project & run directly via project:// (0-byte hardlink)
holo-project "project://node/sectium-browser?from=repository://github.com/awesome-os/sectium-browser@main"

Built-in Shell Shortcuts: Ctrl+B (vertical tab sidebar) · Tabgruppen (colored collapsible groups) · Ctrl+Shift+A (Tab-Suche) · Ctrl+\ (side-by-side Split Tabs).

For native post-Chromium display composition (Skia, Dawn WebGPU, Blink, Qt, Kitty-Ink TTY + first-class StealifyLang), see awesome-os/sectium.

3. Get Awesome-OS Linux Desktop Running

Launcher ≡ Installer: Boot or run awesome-os-desktop, pick your Desktop and Greeter on startup, and it projects on launch via project:// + v11 CAS using static musl awesome-os/coreutils (zero BusyBox coreutils). 

# Install awesome-os-desktop locally into ./bin/
holo-pm install repository://github.com/awesome-os/awesome-os-desktop@main

# Launch the Startup Desktop & Greeter Chooser
./bin/awesome-os-desktop

# Or jump directly into a specific Linux Desktop projection:
holo-project "project://coreutils/omarchy?from=repository://github.com/awesome-os/t2desktop-omarchy@main"
holo-project "project://coreutils/noctalia?from=repository://github.com/awesome-os/t2desktop-noctalia@main"
holo-project "project://node/kitty-ink?from=repository://github.com/awesome-os/awesome-os@main"

Bootable Linux ISO / OCI Image

# Run minimal FROM scratch OCI container (static musl awesome-os/coreutils + v11 CAS)
docker run --rm -it ghcr.io/awesome-os/t2linux:latest /bin/sh

# Or download bootable UEFI/BIOS ISO (x86_64 / aarch64)
# https://github.com/awesome-os/t2linux/releases/latest
